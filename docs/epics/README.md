# Эпики MVP

Девять эпиков соответствуют этапам Э0–Э8 [плана реализации](../../IMPLEMENTATION_PLAN.md). Документы содержат исходный объём работ; актуальное выполнение задач отслеживается в GitHub Issues.

| [Э1: Основа проекта, окружения, вход и автоматические проверки](E1.md) | [E0](E0.md) | [#2](https://github.com/Bambale0/crm_for_max/issues/2) |
| [Э2: Ручная диспетчерская, заявки и управление доступом](E2.md) | [E1](E1.md) | [#3](https://github.com/Bambale0/crm_for_max/issues/3) |
| [Э3: Надёжный MAX Observer и приём событий](E3.md) | [E1](E1.md) | [#4](https://github.com/Bambale0/crm_for_max/issues/4) |
| [Э4: Staff Bot, действия исполнителя и уведомления](E4.md) | [E2](E2.md), [E3](E3.md) | [#5](https://github.com/Bambale0/crm_for_max/issues/5) |

Зависимости в таблице определяют начало работ. Связывание AI-сигналов с заявками в Э5 требует результата Э2, а сквозная приёмка Э5 — результата Э4. Эти условия не блокируют старт независимой AI-работы после Э3.

Э7 подтверждает допуск к пилоту. Реальный пилот и окончательная приёмка входят в Э8.

Перед исполнением разбивайте эпик на задачи до 16 часов с критериями приёмки и необходимыми проверками. Относительные недели и роли взяты из плана; календарные даты и конкретные исполнители ещё не назначены.

Для нового эпика доступен [шаблон GitHub Issue](../../.github/ISSUE_TEMPLATE/epic.md).
