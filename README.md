# Единая цифровая диспетчерская УК

Система для управляющей компании: анализ домовых чатов MAX, AI-сигналы для оператора, управляемые заявки и работа сотрудников через отдельного MAX-бота.

Основной процесс: сообщение → контекстный анализ → сигнал → подтверждение оператора → заявка → назначение → выполнение → контроль сроков и аналитика.

## Состояние проекта

Реализована первая поставка backend: FastAPI, PostgreSQL с миграциями, Redis,
вход через подписанные данные MAX Mini App, сессии, аудит входа и проверки CI.
Доступ сотрудников задаётся MAX ID в env. На dev-сервере реальные токены не
нужны; без них вход отключён. Есть отдельная диагностика MAX API только для чтения.

Интерфейс CRM, заявки, обработка событий ботов и AI ещё не реализованы.
Эпики Э0 и Э1 остаются открытыми: реальные сценарии MAX проверяются после
подготовки env и тестовых ботов при деплое.

## Начало работы

Для запуска следуйте [инструкции разработчика](docs/development.md).
Для тестов используются отдельные PostgreSQL и Redis; реальные чаты и токены
MAX не требуются. Перед развитием ядра CRM уточняются переходы заявок, SLA,
модель доступа и порядок обработки данных из Э0.

AI формирует сигналы; официальную заявку создаёт уполномоченный сотрудник. Внутренние данные CRM доступны только сотрудникам в пределах их прав.

Секреты и рабочие данные не включаются в Git. Политика изменений и условия production-операций определены в `AGENTS.md`.
